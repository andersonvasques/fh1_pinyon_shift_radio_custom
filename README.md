# Forza Horizon 1 – Custom Radio Music (Pinyon Shift)

🇺🇸 English | [🇧🇷 Português](#-português)

A step-by-step guide for Windows on how to add your own music to the Forza Horizon 1 radio stations when running the game through the **Pinyon Shift** emulator/decompiler (**PinyonShift-Launcher**).

The guide covers preparing the MP3 files, generating the mod with the `build-fh1-radio.py` script, enabling it in the launcher and fixing the "silent radio" bug.

📖 **Guide:** [English](docs/en-US/fh1_pinyon_shift_radio_custom_en.md) · [PDF](docs/en-US/fh1_pinyon_shift_radio_custom_en.pdf)
